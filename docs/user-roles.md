# User Roles & Authorization Matrix — OrphanCare AI

| Role | Access & Capabilities |
| :--- | :--- |
| **Admin / Organization** | Full access to manage children profiles, review AI match recommendations, approve sponsorships, and track overall progress. |
| **Donor / Sponsor** | View approved opportunities, fund scholarships/needs, track individual sponsorship impact. |
| **Volunteer** | Register skills & availability, accept mentorship assignments, submit progress notes. |
| **Child / Caregiver** | View assigned development plans, track personal goals, view approved opportunities. |
