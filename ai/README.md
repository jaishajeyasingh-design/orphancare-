# OrphanCare AI — AI Layer

This directory contains the AI microservice architecture, including autonomous agents, prompt templates, evaluation frameworks, and LLM integrations.

## Agent Structure
Each agent in `agents/` is structured as follows:
- `agent.py`: Agent execution logic & agent workflow
- `prompt.py`: Prompt templates & system instructions
- `schemas.py`: Input/Output schema definitions
- `service.py`: Agent service entry point
- `README.md`: Agent specific documentation
